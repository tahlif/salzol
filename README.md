# סַלְזוֹל (SalZol) — משווים סל, קונים בזול

השוואת מחירים בין רשתות השיווק בישראל לפי אזור מגורים, ישירות מקבצי שקיפות המחירים שהרשתות מחויבות לפרסם לפי חוק קידום התחרות בענף המזון. סטטי לחלוטין — אפס שרתים, אפס עלות אחסון.

## איך זה עובד

```
GitHub Actions (כל לילה, חינם)
  └─ pipeline/fetch.js   קבצי סניפים לכל רשת + PriceFull לסניף מייצג בכל מחוז → cache
  └─ pipeline/build.js   פירסור, הצלבת ברקודים לכל מחוז, שמירת שינויי מחיר בלבד → site/data
       └─ git commit     הדאטה חוזר לריפו → האתר הסטטי מתעדכן
```

- מפת OpenStreetMap אינטראקטיבית (Leaflet) עם סיכה צבעונית לכל סניף; קואורדינטות מ-Nominatim (`pipeline/geocode.js`, אינקרמנטלי, נשמר ב-`pipeline/geo.json`)
- בחירת יישוב מתוך כל יישובי ישראל (רשימת הלמ"ס דרך data.gov.il, `pipeline/fetch-cities.js` → `pipeline/cities-il.json`); היישוב ממופה לאחד מ-7 אזורי השוואה (6 מחוזות + יו"ש)
- מצב "סניפים קבועים": בחירת 2-4 סניפים מתוך כל ~805 הסניפים (בפאנל חיפוש או ב-⭐ מתוך חלונית סניף במפה); המחיר לכל סניף נלקח מסניף-הבסיס של הרשת באזור שלו
- ריחוף על סיכה פותח את כרטיס הסניף המלא (אין טולטיפ נפרד); זום בגלגלת/צביטה
- תמונות מוצרים מ-Open Food Facts לפי ברקוד (טעינה עצלה בדפדפן, cache ב-localStorage; כיסוי חלקי למותגים ישראליים); פירות/ירקות מקבלים אימוג'י
- `site/data/d/<district>/index.json` — אינדקס חיפוש אזורי (כל המוצרים, גם כאלה שברשת אחת - מוצרי חשמל קטנים, מותגים פרטיים)
- `site/data/d/<district>/s/<NN>.json` — 100 shards לפי 2 ספרות אחרונות של הברקוד; כל מוצר: מחיר נוכחי לכל רשת + היסטוריית שינויים (מבנה shards בגלל מגבלת 20K קבצים של Cloudflare Pages)
- `site/data/stores-all.json` — כל הסניפים, לפי אזור ורשת
- `pipeline/branches.json` — הסניף המייצג שנבחר לכל רשת/מחוז; נשמר בגיט כדי שההיסטוריה תמשיך על אותו סניף

היסטוריה נשמרת **רק כשמחיר משתנה** — המאגר גדל לאט מאוד (~28MB לכל הארץ ביום הראשון).

## הרצה מקומית

```
node pipeline/fetch.js   # ~35 קבצים, כמה דקות
node pipeline/build.js
node serve.js            # http://localhost:8737
```

## פריסה (חינם)

1. ריפו בגיטהאב — `.github/workflows/nightly.yml` ירוץ לבד כל לילה (06:30 שעון ישראל).
2. Cloudflare Pages → חיבור לריפו, output directory = `site`.

## דיוק מיקומים

`node pipeline/verify-geo.js` מפיק דו"ח אחד-אחד (`pipeline/geo-report.txt`) עם רמת הוודאות של כל סניף. שלוש דרכים לשפר:
1. **Google Places (מומלץ, ~100%)**: מפתח API חינמי במכסה החודשית → `pipeline/google-key.txt` → `node pipeline/geocode-google.js` (הוראות בראש הקובץ).
2. **עקיפה ידנית**: `pipeline/geo-overrides.json` — `"chain:store": {"lat":.., "lng":..}` גובר על הכול.
3. סיכות ברמת-עיר מוצגות מעומעמות ומקווקוות במפה — לא מתחזות למדויקות.

## ידוע וטרם טופל

- מבצעים (קבצי Promo) לא נכללים — מחירי מדף בלבד.
- מחירי כל עמודה נלקחים מסניף-הבסיס של הרשת באותו אזור (41 קבצים נמשכים), לא מכל סניף וסניף — גם ב"סניפים קבועים".
- פירות/ירקות מוצלבים לפי שם (אין ברקוד אוניברסלי) — רשימה של 31 מוצרי יסוד ב-`build.js`, ניתן להרחבה.
- מוצרי חשמל גדולים (טלוויזיות/מקררים): רשתות החשמל לא כפופות לחוק שקיפות המחירים — אין מקור נתונים חינמי. מוצרי חשמל קטנים (קומקום, טוסטר) כן מופיעים בקבצי הסופרים ונכללים אוטומטית כשיש ברקוד משותף.
- פארם (סופר-פארם) אפשרי — הפורטל פתוח, טרם חובר.
